# AI Fake News and Misinformation Detection System

## Overview

This project detects whether a news headline is Real or Fake using Machine Learning and NLP techniques.

## Features

- Fake News Detection
- TF-IDF Vectorization
- Linear SVM Classifier
- Passive Aggressive Classifier
- DistilBERT Comparison Model
- LIME Explainable AI
- Streamlit Web Application
- SQLite Database
- Dataset Insights Dashboard

## Dataset

- PolitiFact
- GossipCop

## Technologies Used

- Python
- Scikit-Learn
- Streamlit
- SQLite
- Transformers
- DistilBERT
- LIME

## Model Performance

| Model | Accuracy |
|---------|---------|
| Passive Aggressive | 80.00% |
| Linear SVM | 84.07% |
| DistilBERT | 85.93% |

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
